# Telegram-интеграция

CRM отправляет сообщение в Telegram только после создания новой заявки из Google Sheets. Ручные заявки уведомление не создают, а уже импортированные строки таблицы повторно не отправляются.

## Настройка

В локальном `.env` должны быть заданы:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=id_личного_чата_или_группы
```

Файл `.env` исключён из Git. После изменения настроек сервер нужно перезапустить.

Для личного чата пользователь должен сначала открыть бота и нажать **Start**. Для группы бота нужно добавить в группу и разрешить ему отправлять сообщения.

## Как работает доставка

1. CRM при запуске и раз в 60 секунд проверяет Google Sheets; администратор также может нажать «Обновить из Google Sheets».
2. Новая заявка и запись очереди создаются вместе в одной транзакции SQLite.
3. Бот отправляет имя, тариф, телефон, Telegram, запрос, назначенного менеджера и дату заявки.
4. Только после ответа Telegram об успешной доставке запись получает статус `sent`.
5. При сетевой ошибке запись остаётся `pending` и повторно отправляется при следующей синхронизации.

Очередь хранится в таблице `telegram_notifications` базы `data/crm.sqlite`.

## Диалоги с клиентами

Вкладка **«Чаты»** принимает сообщения клиентов через long polling и позволяет менеджеру отвечать текстом или файлом. Для каждой заявки CRM создаёт персональную ссылку `https://t.me/<bot>?start=<token>`. После нажатия клиентом **Start** постоянные Telegram `user_id` и `chat_id` связываются с заявкой.

- Алина и Паша видят только назначенные им чаты; Вася видит все, включая непривязанные.
- Сообщение сначала сохраняется в SQLite, затем отправляется в Telegram.
- Входящие и исходящие файлы до 20 МБ сохраняются в `data/telegram-files/`.
- `@username` и телефон используются только для автоматической подсказки; основная привязка выполняется персональным `start`-токеном.
- Один Telegram-контакт имеет единую историю и может быть связан с несколькими заявками.

Long polling запускается внутри постоянного Node-процесса CRM. Переменная `TELEGRAM_POLLING_ENABLED=false` отключает его, например при переходе на production webhook. Telegram не допускает одновременное использование `getUpdates` и webhook.
