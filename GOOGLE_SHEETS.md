# Подключение Google Sheets

CRM автоматически получает новые заявки из подключённой Google Sheets. Сервер опрашивает CSV-представление листа при запуске и затем раз в 60 секунд. Администратору также доступна кнопка **«Обновить из Google Sheets»** для немедленной синхронизации. Ручное создание заявок продолжает работать независимо.

## Обязательные колонки

Первая строка листа должна содержать заголовки в точности:

1. `Отметка времени`
2. `Выберите продукт`
3. `Как к вам обращаться`
4. `Ваш номер телефона для связи`
5. `Ваш никнейм в Telegram`
6. `Запрос`

Порядок колонок может меняться: импортёр ищет их по названию. Дополнительные колонки не мешают синхронизации.

Допустимые продукты:

- `Обучение с куратором`
- `Самостоятельное обучение`
- `Обучение с VIP сопровождением от автора курса`
- `Часовая консультация`

Эти же значения используются в выпадающих списках ручного создания и редактирования заявок и оплат.

## Подключённый лист

Ссылка на опубликованный CSV уже сохранена в серверной части проекта. Дополнительная настройка `.env` не требуется. Переменная `GOOGLE_SHEETS_CSV_URL` оставлена только как необязательная возможность временно подключить тестовый лист.

Новая строка появляется в колонке «Новая заявка» максимум через минуту или сразу после нажатия кнопки ручного обновления.

Заявки распределяются поровну между Алиной и Пашей: каждая новая запись назначается менеджеру, у которого сейчас меньше заявок с источником `google_sheets`; при равенстве первой получает Алина. Вася имеет роль администратора и видит обе очереди.

## Как поля попадают в CRM

| Google Sheets | CRM |
|---|---|
| Отметка времени | Дата заявки |
| Выберите продукт | Тариф |
| Как к вам обращаться | Имя |
| Ваш номер телефона для связи | Телефон |
| Ваш никнейм в Telegram | Telegram |
| Запрос | Запрос |

Новая заявка получает статус `new`, источник `google_sheets` и одного из двух менеджеров. Каждой строке вычисляется внешний идентификатор из отметки времени и контактов. Уникальный индекс SQLite не позволяет повторно загрузить ту же заявку после перезапуска или очередного опроса.

## Конфиденциальность

Публикация CSV означает, что любой человек, получивший длинную ссылку, сможет прочитать лист. Ссылка хранится только на сервере и не попадает в клиентский JavaScript, но публикация всё равно не подходит для особо чувствительных данных.

Для полностью закрытой таблицы нужен другой режим:

1. проект в Google Cloud;
2. включённый Google Sheets API;
3. сервисный аккаунт и JSON-ключ;
4. доступ к таблице для email сервисного аккаунта;
5. публично доступный или постоянно работающий сервер CRM.

Текущая реализация использует опубликованный CSV, потому что это единственный вариант, который можно сразу проверить на localhost без OAuth и внешнего callback URL.
